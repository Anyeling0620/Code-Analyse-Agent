# Self-hosted faces

These variable WOFF2 files are bundled with the frontend so the workspace never
depends on a third-party font stylesheet.

| File | Family | Source | License |
| --- | --- | --- | --- |
| `archivo-latin-wght-normal.woff2` | Archivo (UI / headings) | [Fontsource](https://fontsource.org/fonts/archivo) | SIL Open Font License 1.1 |
| `source-serif-4-latin-wght-normal.woff2` | Source Serif 4 (report prose) | [Fontsource](https://fontsource.org/fonts/source-serif-4) | SIL Open Font License 1.1 |
| `azeret-mono-latin-wght-normal.woff2` | Azeret Mono (code / data) | [Fontsource](https://fontsource.org/fonts/azeret-mono) | SIL Open Font License 1.1 |

Chinese glyphs fall back to the reader's system CJK faces (Songti / Noto Serif
CJK for prose, PingFang / Microsoft YaHei / Noto Sans CJK for UI).
