THESIS
The workspace is a boxed technical reference manual opened to a live section: every answer is a punched milk-acetate leaf laid over one full-strength section color, and the app refuses the generic white chat shell. Standard web navigation and controls stay; the world enters only through type, palette, density, and one signature move.

OWN-WORLD
Deep ink case (#1B2024) and index board; paper field #F4F1E6; milk acetate #FBF8EE. Section hues at full strength: oxide orange, chrome yellow, grass, teal, ultramarine, violet, sienna. Vermilion is held out for errors and destructive actions. Source Serif 4 carries report prose; Archivo carries UI and headings; Azeret Mono carries tool names, IDs, metrics, and code. Signature material: punched holes, a 1px cut edge, a short hard shadow, and a stepped tab rail. Motion is steps(2) at 90ms; no easing curve.

STORY
An engineer opens the tool and reads it as a working reference, not a chatbot: sessions are an index, the current answer is a leaf, tool evidence lifts off the page, and report sections are tabbed. They read the report, inspect evidence, keep asking, then export or share.
